# 使用指南

编译和启动命令见 [README](../README.md#编译)。

## 第一次配置

选择 `只读查询讲座`，输入一卡通号和统一认证密码。查询结束后退出；再次启动可回到菜单。学校要求短信认证时按提示输入，登录图形验证码暂不支持。

按 [OCR 配置](OCR_MODEL.md) 准备文件，再选择 `配置 OCR 文件`，填写：

1. `common_old.onnx` 模型路径。
2. 配套的 `ddddocr-charset.json` 路径。
3. ONNX Runtime 动态库路径，Windows 使用 `.dll`，Linux 使用 `.so`。

只读查询无需 OCR。移动模型或运行库后需更新路径。

## 筛选

选择 `修改筛选与网络偏好`。多个值用英文 `;` 或中文 `；` 分隔。

| 配置 | 规则 |
| --- | --- |
| 指定讲座完整名称 | 按完整标题匹配，填入后忽略类别和校区条件 |
| 讲座类别、校区 | 未指定标题时生效；留空表示不限 |
| 线上、线下 | 默认都开启；关闭某一项会排除该类型 |
| 缓冲分钟数 | 两场活动之间至少需要的间隔，范围为 0–1440 |
| 系统代理 | 默认关闭；需要代理时再开启 |

名称、类别和校区均为精确匹配，标题应完整复制。线上类型根据标题中的“线上”或地点中的“腾讯会议”“线上”判断，可能误判。

满员、未开放、预约已结束、已预约或时间冲突的场次会被排除。指定名称仍受这些限制。

## 预约

选择 `查询并选择讲座预约`，用方向键移动、空格勾选、回车继续。上次选择可能会预选；本次未选任何场次则退出。

已有预约、所选场次和本批刚成功的预约均参与冲突检查，线上也一样。缓冲为 0 时允许首尾相接；为 15 时至少间隔 15 分钟。所选场次互相冲突时需重新选择。

确认后逐场提交，每场最多尝试三次验证码。成功响应还需查询预约记录核验；结果仍不明确时停止后续提交，请到学校系统核查后再重试。取消预约也在学校系统操作。

## 保存的数据

Windows 数据目录为 `%LOCALAPPDATA%\SEU\LectureReserve\data`：

| 文件 | 内容 |
| --- | --- |
| `preferences.toml` | 筛选条件、缓冲时间、代理设置、OCR 路径和上次选择 |
| `credentials.dpapi` | 当前 Windows 用户加密的账号凭据 |
| `session.dpapi` | 当前 Windows 用户加密的登录会话 |

Linux 配置默认位于 `~/.local/share/lecturereserve/preferences.toml`，可通过 `XDG_DATA_HOME` 调整；账号和 Cookie 仅存内存，每次启动重新输入。

Windows 使用 DPAPI 加密保存凭据和会话。换电脑或用户后需重新登录；`更换账号` 菜单会更新凭据并清除旧会话。

## 常见问题

| 现象 | 处理方法 |
| --- | --- |
| 列表里有讲座，却没有可选场次 | 检查开放时间、余量、筛选条件及已有预约冲突 |
| 无法连接，或跳转到 VPN 门户 | 检查当前网络和系统代理；先尝试关闭程序代理选项 |
| 提示模型或动态库不存在 | 填写解压后的实际文件路径；移动文件后重新配置 |
| 连续验证码识别失败 | 本场达到次数上限后结束，可在学校网页手动预约 |
| 保存的凭据无法解密 | 按提示重新输入，或通过 Windows 菜单更换账号 |
