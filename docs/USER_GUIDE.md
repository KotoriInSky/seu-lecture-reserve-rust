# 使用指南

本文对应 1.0.0。程序每次处理一批手动选择的讲座，确认后逐场预约，最后显示结果并退出。

## 编译和启动

安装 [Rust stable](https://rustup.rs/)。Windows 还需要 Visual Studio C++ Build Tools 和 Windows SDK；Ubuntu 安装 `build-essential` 和 `ca-certificates`。Linux 的环境准备见 [Linux 与 WSL2](LINUX.md)。

```sh
git clone https://github.com/KotoriInSky/seu-lecture-reserve-rust.git
cd seu-lecture-reserve-rust
cargo build --release --locked
```

Windows 在 PowerShell 中启动：

```powershell
.\target\release\seu-lecture-reserve.exe
```

Linux 启动：

```bash
./target/release/seu-lecture-reserve
```

建议从已有终端窗口启动，这样程序退出后仍能查看结果。

## 第一次配置

先选 `只读查询讲座`，输入一卡通号和统一认证密码。程序显示讲座列表和已有预约数量后退出。只读查询不需要 OCR，也不会产生预约。

Windows 会加密保存账号和会话，后续优先复用。Linux 每次启动都要重新输入。学校要求短信认证时，按提示输入短信验证码；登录图形验证码挑战暂不支持。

再次启动程序，选择 `配置 OCR 文件`，依次填写：

1. `common_old.onnx` 模型路径。
2. 配套的 `ddddocr-charset.json` 路径。
3. ONNX Runtime 动态库路径，Windows 使用 `.dll`，Linux 使用 `.so`。

文件准备步骤见 [OCR 配置](OCR_MODEL.md)。填写文件的实际路径，不能填写压缩包路径。模型在 CPU 上运行，无需显卡。

## 设置筛选条件

选择 `修改筛选与网络偏好`。多个值用英文 `;` 或中文 `；` 分隔。

| 配置 | 规则 |
| --- | --- |
| 指定讲座完整名称 | 按完整标题匹配，填入后忽略类别和校区条件 |
| 讲座类别、校区 | 未指定标题时生效；留空表示不限 |
| 线上、线下 | 默认都开启；关闭某一项会排除该类型 |
| 缓冲分钟数 | 两场活动之间至少需要的间隔，范围为 0–1440 |
| 系统代理 | 默认关闭；需要代理时再开启 |

名称、类别和校区都采用完整字符串匹配。例如，想预约某个标题含“人工智能”的讲座，需要复制它的完整标题，不能只填“人工智能”。

只想看线上讲座时，开启线上、关闭线下，其他列表按需要留空。程序根据标题中的“线上”或地点中的“腾讯会议”“线上”判断类型，学校填写不规范时可能误判。

指定完整标题也不会绕过类型、余量和时间冲突检查。满员、未开放、已结束预约或已经预约的场次，不会进入可选列表。

## 预约

选择 `查询并选择讲座预约`。程序先询问是否修改上次的筛选偏好，再登录并读取当前列表。

在多选界面中，用方向键移动、空格勾选、回车继续。上次选过且仍符合条件的场次会预选，请检查后再确认。没有勾选任何场次时，程序直接退出。

所选场次互相冲突时，程序列出冲突并要求重新选择。检查通过后，会询问是否开始预约；选择确认后才提交。

已有预约、本次选择以及本批刚成功的预约都参与冲突检查，线上讲座也一样。缓冲为 0 时，一场结束和另一场开始可以在同一时刻；设为 15 时，两场之间至少需要间隔 15 分钟。

当前程序按顺序处理场次，不会等待未来开放时间，也不会在满员后持续候补。

## 查看结果

程序自动获取和识别预约验证码，只提交四位 ASCII 数字。每场最多尝试三次验证码；识别成四位数字也可能读错，最终以学校响应和预约记录为准。

收到成功响应后，程序还会查询预约记录核验。遇到网络超时或不明确的响应，也会先查记录；仍无法确认时，停止后续提交。此时先登录学校系统查看记录，再决定是否重试。

预约取消请在学校系统中操作，CLI 没有取消预约菜单。

## 保存的数据

Windows 数据目录为 `%LOCALAPPDATA%\SEU\LectureReserve\data`：

| 文件 | 内容 |
| --- | --- |
| `preferences.toml` | 筛选条件、缓冲时间、代理设置、OCR 路径和上次选择 |
| `credentials.dpapi` | 当前 Windows 用户加密的账号凭据 |
| `session.dpapi` | 当前 Windows 用户加密的登录会话 |

Linux 普通配置默认位于 `~/.local/share/lecturereserve/preferences.toml`，也可通过 `XDG_DATA_HOME` 调整。Linux 不保存账号和 Cookie。

换电脑或 Windows 用户后，重新输入账号即可。模型移动后，要重新配置路径。Windows 菜单中的 `更换账号` 会更新凭据并清除旧会话。

## 常见问题

| 现象 | 处理方法 |
| --- | --- |
| 列表里有讲座，却没有可选场次 | 检查开放时间、余量、筛选条件及已有预约冲突 |
| 输入关键词后没有结果 | 指定名称要求完整标题，先从只读查询结果中复制 |
| 无法连接，或跳转到 VPN 门户 | 检查当前网络和系统代理；先尝试关闭程序代理选项 |
| 提示模型或动态库不存在 | 填写解压后的实际文件路径；移动文件后重新配置 |
| 提示模型维度或字符表不符 | 使用配套的 `common_old.onnx` 和完整字符配置 |
| 连续验证码识别失败 | 本场达到次数上限后结束，可在学校网页手动预约 |
| 保存的凭据无法解密 | 按提示重新输入，或通过 Windows 菜单更换账号 |
